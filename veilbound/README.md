# Veilbound

A Minecraft **NeoForge** mod (Minecraft 1.21.1, NeoForge 21.1.x, Java 21) about a
shattered sky dimension called **the Veil**: floating islands of purple-black
stone over an endless void, lit by glimmer crystals and ember wisps.

## How to play

1. Craft a **Veil Portal Frame** (voidstone bricks + aetherite + ember core), place
   it, and right-click it with a **Veil Key** to ignite a **Veil Portal**.
2. Step into the portal block to travel between the Overworld and `veilbound:the_veil`.
3. In the Veil, mine **Aetherite Ore** and **Glimmer Shard Ore** (stone tool tier),
   fight **Hollow Husks**, **Veil Reavers** and **Ember Wisps** for **Ember Cores** and
   **Veil Essence**, then mine **Voidstone Ore** (iron tool tier) with Ember gear.
4. Build a **Gravity Anchor** (slow falling + jump aura) and a **Resonant Spire**
   (regeneration aura), and track down the **Crystal Golem** in the Crystal Hollows.
5. Slay the **Hollow King** (3 phases, boss bar, summons wisps) to get the **Void Heart**.

## Content

- **Dimension**: `veilbound:the_veil` — floating-island terrain, lava "sea" at the
  bottom, eternal night, 3 biomes (`veil_expanse`, `crystal_hollows`, `ember_mires`).
- **Blocks (24)**: veilstone set (stone, cobbled, bricks, chiseled, stairs, slab, wall,
  turf), voidstone + bricks, 4 ores, glimmer crystal block, raw-metal blocks,
  portal frame + portal, gravity anchor, resonant spire, ember brazier, 4 plants.
- **Items (~60)**: 8 materials, 3 foods, 15 tools (Ember/Aetherite/Voidsteel tiers),
  4 special melee weapons (Emberbrand Sword = ignite, Stormcaller Greatsword = AoE,
  Voidreaver Scythe = lifesteal, Aetherfang Dagger = fast), Veilbow + Veil Arrow,
  Shard Launcher, Gloom Wand, 4 trinkets (Veil Key, Amulet of Slow Fall, Gravity Ring,
  Veil Cloak), 12 armor pieces with set bonuses, 8 spawn eggs.
- **Entities (12)**: Glimmerfox, Shardling, Veil Moth (passive/ambient); Hollow Husk,
  Veil Reaver, Ember Wisp, Crystal Golem (hostile, the golem is biome-restricted);
  **Hollow King** (3-phase boss with boss bar); projectiles: ember orb, shard bolt,
  gloom orb, veil arrow.
- **Effects**: Ember Mark (damage over time), Gravity Well (slow falling).
- **Systems**: custom portal teleport with cooldown, block-entity auras, set bonuses,
  loot tables, recipes (crafting/smelting/blasting/stonecutting), advancements,
  tags, particles, sounds, common config (`config/veilbound-common.toml`).

## Build & run

```bash
./gradlew build          # produces build/libs/veilbound-1.0.0.jar
./gradlew runClient      # launch the game with the mod
./gradlew runServer      # dedicated server
```

Resources (textures, models, loot, recipes, worldgen, lang) are generated by
`tools/generate_resources.py` (`python3 tools/generate_resources.py`); the checked-in
files under `src/main/resources` are its output. **Textures and sound files are
placeholder art** — swap the PNGs under `assets/veilbound/textures` and add `.ogg`
files under `assets/veilbound/sounds` to replace them.

## Project layout

```
src/main/java/com/lunarxo/veilbound/
  Veilbound.java            mod entry point
  registry/                 DeferredRegister hubs (blocks, items, entities, ...)
  block/ + block/entity/    portal, gravity anchor, resonant spire, plants
  item/                     veil key, teleporter, weapons, trinkets, arrows
  entity/                   mobs, boss, projectiles
  client/                   renderers, particle
  event/                    game-bus events (armor set bonuses)
src/main/resources/         generated assets + data (see tools/generate_resources.py)
tools/                      resource generator + vanilla JSON templates
```
